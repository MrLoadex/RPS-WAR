# Piedra Papel Tijeras War

Piedra Papel Tijeras War es un juego de estrategia multijugador para dos jugadores, desarrollado completamente en JavaScript sin ningún framework, excepto Node.js y Socket.io para el backend. Este juego combina los conceptos de Age of War y el clásico Piedra, Papel o Tijeras, ofreciendo un sistema de salas privadas y usuarios temporales al estilo de agar.io.

## Descripción del Juego

Después de un registro temporal rápido, puedes crear o unirte a una sala para comenzar a jugar. El juego presenta una plataforma con dos puños enfrentados, cada uno representando a un jugador. Puedes identificar tu lado por la ubicación de tus vidas. Debajo de la pantalla, hay tres botones, cada uno representando un elemento. Al presionar un botón, lanzas una tropa desde tu base que representa el elemento seleccionado, avanzando hacia tu rival. Si los elementos chocan, se aplican las reglas clásicas de Piedra, Papel o Tijeras. Si un elemento alcanza la base rival, el oponente pierde una vida. El primer jugador en perder las tres vidas pierde la partida.

## Requisitos del Sistema

- Node.js
- JavaScript

## Instrucciones de Instalación

1. Instala Node.js en tu sistema.
2. Clona este repositorio.
3. Instala las dependencias del proyecto ejecutando `npm install` en la raíz del proyecto.
